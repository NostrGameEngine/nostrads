Use NostrAds

Advertisers

Publish signed bid events on Nostr and delegate their management to a delegate service with a budgeted NWC URL.

Open advertiser console

Delegate providers

Run a delegate service to manage advertisers’ bids, enforce offerer filters, and process Lightning payouts.

Host a delegate service

Game developers

NostrAds is built into the Nostr Game Engine, so you can display ads directly inside your game world.

Game integration docs

Web developers

Create an app key and publish a Nostr metadata event with a lud06 or lud16 address for payouts. Add the client to your page, then place ad spaces where you need them.

Choose the formats, languages, categories, and advertisers your app accepts.
